# Forecasting

Forecasting portfolio with hierarchical, spatial, and time series models applied to housing, energy, retail, and utilities data.

## Projects

### Zillow Sales House Forecasting

End-to-end forecasting project for monthly Zillow housing data, including data preprocessing, spatial analysis, statistical benchmarks, machine learning benchmarks, deep learning models, hierarchical reconciliation, and error analysis.

## Interactive spatial maps

The Zillow spatial analysis includes interactive H3-based maps generated from latitude and longitude features.

- [Combined H3 spatial map](https://albertogudinoochoa.github.io/Forecasting/Zillow%20Sales%20House/Spatial%20Analysis/Outputs/zillow_h3_combined_map.html)
- [H3 market density map](https://albertogudinoochoa.github.io/Forecasting/Zillow%20Sales%20House/Spatial%20Analysis/Outputs/zillow_h3_market_density.html)
- [H3 sales concentration map](https://albertogudinoochoa.github.io/Forecasting/Zillow%20Sales%20House/Spatial%20Analysis/Outputs/zillow_h3_sales_concentration.html)

## Methods

- Hierarchical time series forecasting
- Spatial feature engineering
- H3 spatial indexing
- Statistical forecasting benchmarks
- Machine learning forecasting benchmarks
- Deep learning forecasting benchmarks
- Forecast reconciliation
- Walk-forward cross-validation
- Error and bias analysis
